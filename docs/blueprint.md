# **App Name**: Festiva AI

## Core Features:

- Intelligent Wish Synthesizer: An AI-powered tool that generates personalized, emotional birthday messages based on relationship depth and shared memories provided by the user.
- Dynamic Canvas Celebration: A high-performance confetti system utilizing the HTML5 Canvas API to create festive explosions when the hidden message is revealed.
- Glassmorphic Interaction Panel: A sophisticated card interface featuring translucent glass effects, modern typography, and a reveal button for the personalized content.
- Celebration Soundtrack: Integration of audio controls to trigger curated celebratory sounds perfectly synced with visual confetti bursts.
- Media Showcase: An elegant photo placeholder with glowing circular borders to display the person being celebrated with stylized effects.
- Permanent Greeting Storage: The ability to save and share personalized cards via unique links using a cloud-based storage solution.

## Style Guidelines:

- The primary color is a vibrant celebratory Red (#E63946) to anchor the emotional core of the experience.
- The background uses a deep, desaturated dark charcoal with a red tint (#1C1112), providing a luxurious and moody backdrop for light to pop.
- The accent color is a high-contrast Rose Magenta (#E6399D), used for CTAs and highlighted text elements to create depth and energy.
- Recommended Pairing: 'Dancing Script' (Cursive/Script) for primary headlines and personal notes, and 'Poppins' (Sans-serif) for body text and navigation elements. Note: currently only Google Fonts are supported.
- Line-art icons with a golden gradient finish to signify quality and festive prestige, mimicking a royal celebration theme.
- Centered, glassmorphic layout focused on vertical rhythm and maximum readability on both mobile and desktop viewports.
- Physics-based particles for confetti and a gentle 3D hover effect (floating animation) for the main glass card container.
